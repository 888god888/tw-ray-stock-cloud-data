台股選股 v13.2：下方操作列與樹精靈開啟

安裝網站：解壓縮後，到 GitHub 儲存庫的 docs/ 資料夾，把本包 docs/index.html、docs/app.js、docs/app.css、docs/sw.js 四個同名檔案覆蓋並提交。GitHub Pages 完成發佈後，iPhone 主畫面 PWA 請在有網路時完全關閉後重新開啟；必要時再開一次。盤後資料 docs/data 不在更新包內，不會覆蓋 10/12 的資料。

iPhone 首次設定（一次即可）：
1. 打開「捷徑」App → 新增捷徑，名稱必須是「開啟樹精靈」。
2. 加入「拷貝到剪貼板」動作，內容指定為「捷徑輸入」。
3. 加入「打開 App」動作，指定「國泰證券 樹精靈」，儲存。
4. 選股網站打開一檔股票，在詳情中點「開啟樹精靈」；首次會展示這份設定說明。設定完成後點「已設定捷徑」，再點下方「開啟樹精靈」。iOS 可能詢問是否開啟「捷徑」，請允許。

之後每檔股票點下方「開啟樹精靈」，捷徑會收到當前代號、複製代號、開啟樹精靈。進到 App 後在搜尋框貼上代號。若只需要代號，直接點下方「複製代號」。樹精靈目前沒有已核實的個股直達連結，因此不會自動進入該股票頁。
